# Chapter 29: Reference Managers — Your Digital Library

## Why You Need a Reference Manager

If you are still manually formatting bibliographies, copying DOIs into Word documents, or — heaven forbid — retyping reference lists by hand, this chapter will change your life. A reference manager is software that stores, organizes, and formats your citations and bibliographies automatically. It is the single most important productivity tool for any researcher, and it is the one thing I wish someone had shown me during my first semester.

Think of it this way: you will read hundreds of papers during your research career. You will cite dozens in a single manuscript. A reference manager lets you build a personal library that grows with you, and it handles the tedious formatting work so you can focus on the actual thinking.

Three reference managers dominate the academic landscape. Here is how they stack up:

### My Recommendation: Zotero

Zotero wins for most researchers, especially students. It is free, open source, actively developed, and has an enormous community. The plugin ecosystem is rich, and it handles everything from citation capture to bibliography generation. If you are starting from scratch, start with Zotero.

## Step-by-Step: Setting Up Zotero

### Step 1: Install Zotero

1. Go to [zotero.org](https://www.zotero.org/) and download the desktop application.
2. Install it like any other program.
3. Create a free Zotero account — this enables syncing across devices and shared libraries.

### Step 2: Install the Browser Connector

The Zotero Connector is a browser extension that captures citation metadata (and often full-text PDFs) from any webpage with a single click.

1. After installing Zotero, visit [zotero.org/download](https://www.zotero.org/download/).
2. Install the connector for your browser (Chrome, Firefox, Edge, or Safari).
3. You will see a Zotero icon appear in your browser toolbar. The icon changes shape depending on what it can capture — a newspaper article for a journal page, a book for a book listing, a folder for search results with multiple items.

**How to use it:** Navigate to any journal article page (on PubMed, Google Scholar, or a publisher site like APA PsycNET). Click the Zotero connector icon. Zotero saves the citation metadata and attempts to grab the PDF. That is literally it — one click.

### Step 3: Install the Word Plugin

Zotero installs a plugin for Microsoft Word (and LibreOffice) automatically during installation.

1. Open Microsoft Word.
2. Look for a "Zotero" tab in the ribbon.
3. If it is not there, open Zotero, go to Edit → Preferences → Cite → Word Processors, and reinstall the plugin.

The plugin gives you two key buttons:
- **Add/Edit Citation** — inserts or modifies an in-text citation.
- **Add/Edit Bibliography** — inserts or updates the reference list.

### Step 4: Build Your Library

You have four ways to add references:

1. **Browser Connector** — the fastest method. One click while viewing a paper online.
2. **DOI/ISBN/PMID** — in Zotero, click the magic wand icon, paste a DOI, and it fetches everything.
3. **PDF Drag-and-Drop** — drag a PDF into Zotero. It reads the metadata (author, title, journal) using Google Scholar or CrossRef. This works surprisingly well.
4. **Manual Entry** — for the occasional item that cannot be captured automatically (rare books, unpublished manuscripts, personal communications).

### Step 5: Organize with Collections and Tags

- **Collections** are like folders, but an item can live in multiple collections without duplicating.
- **Tags** are labels you assign (e.g., "review needed," "methodology," "cognitive neuroscience"). Color-coded tags make scanning easy.
- **Related Items** let you link papers to each other — useful for tracking citation chains.

> **Pro Tip:** Create a collection for each project or paper you are writing. When you are working on a manuscript, drag relevant items into that collection. Zotero will only cite items from your active library, so this keeps things clean.

### Step 6: Cite While You Write

1. In Word, place your cursor where you want a citation.
2. Click "Add/Edit Citation" in the Zotero tab.
3. A search bar appears — type the author's name or title.
4. Select the reference. Zotero inserts the in-text citation (e.g., Smith, 2023).
5. At the end of your document, click "Add/Edit Bibliography" to generate the full reference list.

Zotero automatically formats everything according to the citation style you select. Change the style, and every citation and the bibliography update instantly.

## Citation Styles and Journal Requirements

Different journals require different citation formats. Zotero comes with thousands of installed styles (APA 7th, MLA, Chicago, Harvard, Vancouver, and hundreds of journal-specific styles).

To change your citation style:
1. In Word, click "Document Preferences" in the Zotero tab.
2. Search for the style you need (e.g., "APA 7th Edition").
3. Select it and click OK.

All citations and the bibliography regenerate automatically.

### Common Styles in Psychology

| Style | Used By | Format Example |
|---|---|---|
| APA 7th | Most psychology journals | (Smith & Jones, 2023) |
| APA 6th | Legacy (some journals still use) | (Smith & Jones, 2023) |
| Vancouver | Medical journals | (1) |
| Chicago | Some humanities-adjacent journals | Footnotes or author-date |
| Harvard | UK/Australian institutions | (Smith and Jones 2023) |

> **Pro Tip:** Always check the "Instructions for Authors" page of your target journal before you start writing. Some journals have their own modified APA style or a custom format. If a Zotero style does not exist for a journal, search the Zotero Style Repository at [zotero.org/styles](https://www.zotero.org/styles).

## Collaboration with Shared Libraries

Zotero allows you to create **Group Libraries** — shared collections that multiple people can access and edit.

1. Log in to your Zotero account at zotero.org.
2. Go to Groups → Create a New Group.
3. Choose the privacy level: Public, Public with Closed Membership, or Private.
4. Invite collaborators by username.
5. In Zotero desktop, the group library appears in the left sidebar alongside your personal library.

Shared libraries are perfect for research teams. Everyone can add references, annotate PDFs, and the shared library stays synced.

## Mendeley: A Quick Overview

Mendeley is owned by Elsevier and offers a polished, user-friendly experience. It excels at PDF management — the built-in PDF reader with annotation tools is excellent. However, since Elsevier acquired it, some researchers have ethical concerns about supporting a company that profits heavily from publicly funded research.

**When to use Mendeley:**
- You already have a large PDF library and want good PDF annotation.
- Your institution provides Mendeley institutional support.
- You prefer a more visual, drag-and-drop interface.

**Setup is similar to Zotero:** install the desktop app, browser connector, and Word plugin. The free tier gives you 2 GB of cloud storage.

---

## EndNote: When You Need It

EndNote is the industry standard in many large research institutions and labs. It is powerful but expensive. Most universities provide institutional licenses, so check with your library.

**When to use EndNote:**
- Your lab or institution already has licenses and expects you to use it.
- You are collaborating with researchers who use EndNote.
- You need advanced features like term lists or connection files for specific databases.

**The downside:** EndNote is not open source, the interface feels dated compared to Zotero, and it is overkill for most individual researchers.

## Migrating Between Tools

If you are already using one tool and want to switch, do not panic. All three support standard export formats.

**From Mendeley to Zotero:**
1. In Mendeley, select all references → File → Export → BibTeX (.bib).
2. In Zotero, File → Import → select the .bib file.
3. Your references transfer over. PDFs may need re-linking.

**From EndNote to Zotero:**
1. In EndNote, select all → File → Export → choose XML format.
2. In Zotero, File → Import → select the XML file.

> **Pro Tip:** Do this migration once, early. The longer you wait, the larger your library grows, and the more painful the switch becomes.

## PDF Management and Annotation

Modern Zotero (version 6 and above) includes a built-in PDF reader. You can:

- Highlight text in different colors.
- Add sticky notes to specific passages.
- Extract annotations into a standalone note.
- Search across all your annotations.

**Workflow for reading papers:**
1. Save the paper to Zotero (browser connector or DOI).
2. Open the PDF in Zotero's reader.
3. Highlight key findings, methods, and quotes.
4. Right-click annotations → "Add Note from Annotations."
5. This creates a structured note with all your highlights and comments, linked to the original reference.

This annotation-to-note pipeline is incredibly useful when you are writing a literature review. You end up with organized notes for every paper, ready to synthesize.

## Backup and Sync

Zotero syncs your citation metadata (titles, authors, abstracts, tags) for free, with no limit. File attachments (PDFs) get 300 MB free. You can buy additional storage ($20/year for 2 GB, $60/year for 6 GB), or use a workaround:

**The WebDAV workaround:**
1. Set up a free WebDAV service (some cloud providers offer this).
2. In Zotero → Edit → Preferences → Sync → choose "WebDAV" for file syncing.
3. Your PDFs sync to your own storage, bypassing Zotero's limits.

Alternatively, if you only use one computer, just back up your Zotero data folder regularly. It is located at:
- **Windows:** `C:\Users\{username}\Zotero\`
- **Mac:** `/Users/{username}/Zotero/`
- **Linux:** `/home/{username}/Zotero/`

2. Go to Google Scholar and search for "cognitive neuroscience working memory."
3. Click the Zotero connector folder icon (appears when multiple results are on the page).

## Common Mistakes to Avoid

1. **Not using a reference manager at all.** This is the biggest mistake. Manual citation management is error-prone and wastes hours.
2. **Entering references manually when automatic capture works.** Always try the browser connector or DOI lookup first.
3. **Not checking auto-captured metadata.** Zotero sometimes gets things wrong — wrong year, missing page numbers, garbled titles. Always skim the saved metadata.
4. **Mixing citation styles in one document.** Pick one style and stick with it. Zotero makes switching trivial, so do it at the document level.
5. **Forgetting to sync.** If your hard drive fails, an unsynced library is gone. Set up sync on day one.

## Summary

A reference manager is not optional — it is essential infrastructure. Zotero is the best choice for most researchers: free, powerful, open source, and backed by a vibrant community. Set it up once, learn the browser connector and Word plugin workflow, and you will save hundreds of hours over your research career. The time you invest in learning it now pays dividends for every paper you write from here on.
