# 📚 Research Guide Project

A comprehensive research methodology guide and academic paper collection for Psychology research, designed for M.A. Psychology students preparing for UGC NET/JRF.

## 🎯 Project Overview

This repository contains:

1. **Research Guide** (`guide/`) — A structured 5-part guide covering the full research lifecycle
2. **Paper Collection** (`papers/`) — Curated academic papers organized by field of application
3. **Book References** (`books/`) — Key psychology textbooks in PDF and markdown
4. **Indices & Metadata** (`*.json`) — Searchable indices for papers and collections
