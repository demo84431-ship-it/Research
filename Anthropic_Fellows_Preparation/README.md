| Detail | Info |
|--------|------|

| **Compute** | ~$15,000/month |
| **Output** | Co-first authored research paper |
| **Post-program** | 40%+ join Anthropic full-time |
| **Next deadline** | ~July 2027 (estimated) |
| **Location** | Remote-friendly, Bay Area / London preferred |
