## Learning Resources (Ranked by Priority)

### Python for ML
1. **Kaggle Learn** (free) — Hands-on micro-courses
2. **Python Data Science Handbook** (free online) — Jake VanderPlas
3. **Automate the Boring Stuff** (free online) — Python basics refresher

### Machine Learning
1. **fast.ai** (free) — Top-down, practical approach
2. **Andrew Ng's ML Specialization** (Coursera) — Bottom-up, theoretical
3. **Scikit-learn documentation** — Best reference
4. **Hands-On ML with Scikit-Learn** (Aurélien Géron) — Comprehensive book

### Deep Learning
1. **fast.ai Part 2** (free) — Deep learning from scratch
2. **PyTorch tutorials** (free) — Official tutorials
3. **3Blue1Brown: Neural Networks** (YouTube) — Best visual explanation
4. **The Illustrated Transformer** (blog) — Must-read

### NLP & Transformers
1. **Hugging Face Course** (free) — Best practical NLP course
2. **Stanford CS224N** (YouTube) — Academic NLP course
3. **Speech and Language Processing** (Jurafsky & Martin) — Free textbook

### AI Safety
1. **Anthropic's Alignment Science Blog** — Primary source
2. **MIRI's research** — Theoretical foundations
3. **LessWrong: AI Safety** — Community discussions
4. **AGI Safety Fundamentals** (free course) — Structured introduction
5. **AI Safety Camp** — Hands-on experience
