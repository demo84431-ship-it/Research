# Project 1: Sentiment Analysis of Therapy Data

> **Phase 4 project — NLP + Psychology intersection**

---

## Overview

Build a sentiment/emotion analysis model that analyzes therapy-related text data, demonstrating both NLP skills and psychology domain knowledge.

---

## Steps

1. **Data Collection**
   - Use publicly available therapy conversation datasets
   - Or scrape Reddit mental health forums (r/therapy, r/anxiety) with ethical considerations
   - Or use your own survey data with open-ended responses

2. **Preprocessing**
   - Text cleaning (remove special characters, lowercasing)
   - Tokenization using Hugging Face tokenizers
   - Handle psychology-specific vocabulary

3. **Model Building**
   - Start with pre-trained BERT model
   - Fine-tune on therapy text data
   - Classify emotions: anxiety, depression, hope, anger, neutral

4. **Evaluation**
   - Accuracy, precision, recall, F1
   - Confusion matrix
   - Error analysis — what does the model get wrong?

5. **Documentation**
   - Clean README with project description
   - Code comments explaining decisions
   - Results visualization
