# Project 2: Psychology-Informed Alignment Analysis

> **Phase 6 project — connects psychology to AI safety directly**

---

## Overview

Apply psychological frameworks (motivation theory, threat response) to analyze and predict AI model behavior in alignment-relevant scenarios.

---

## Steps

1. **Literature Review**
   - Map psychological theories to AI alignment concepts
   - Self-Determination Theory → goal preservation
   - Threat response → resistance to shutdown
   - Cognitive dissonance → alignment faking

2. **Experimental Design**
   - Design scenarios varying threat level and goal structure
   - Use open-source models (Llama, Mistral) for testing
   - Create controlled conditions inspired by psychology experiments

3. **Data Collection**
   - Run models across multiple conditions
   - Record responses, reasoning traces
   - Code behaviors using psychological frameworks

4. **Analysis**
   - Statistical analysis of behavioral patterns
   - Map findings to psychological predictions
   - Identify where psychological frameworks predict AI behavior

5. **Write-up**
   - Paper-ready format
   - Clear methodology section
   - Discussion of implications
