# ✅ Application Checklist

> Complete this checklist before submitting your application

---

## Materials to Prepare

### Resume/CV
- [ ] Updated with latest education and publications
- [ ] Python skills prominently listed
- [ ] ML/AI projects listed (once completed)
- [ ] Research experience highlighted
- [ ] Publications listed with links
- [ ] Clean, professional formatting (1–2 pages)
- [ ] Tailored for AI safety audience

### Research Proposal
- [ ] Clear research question (one sentence)
- [ ] Background section (why this matters)
- [ ] Methodology section (how you'll do it)
- [ ] Expected outcomes
- [ ] 4-month timeline
- [ ] Connection to Anthropic's priorities
- [ ] Proofread by someone else

### Application Essay
- [ ] Why AI safety? (personal motivation)
- [ ] What unique perspective do you bring?
- [ ] What would you work on during the fellowship?
- [ ] Long-term career vision
- [ ] Specific examples, not generic statements
- [ ] Authentic voice
- [ ] 500–1000 words

### Portfolio/Projects
- [ ] At least 2 ML projects on GitHub
- [ ] Clean code with documentation
- [ ] README files explaining each project
- [ ] At least 1 project connecting psychology + AI
- [ ] Projects demonstrate Python proficiency

### Paper Summaries
- [ ] Read and summarized 10+ AI safety papers
- [ ] Can discuss key concepts fluently
- [ ] Can explain why specific papers matter
- [ ] Notes organized and accessible

---

## Pre-Submission Review

### Content Check
- [ ] All materials tell a consistent story
- [ ] Unique value proposition is clear
- [ ] Technical competence is demonstrated
- [ ] Motivation is genuine and specific
- [ ] Research proposal is feasible in 4 months

### Technical Check
- [ ] All links work (GitHub, papers, etc.)
- [ ] Files are in correct format (PDF for resume)
- [ ] No typos or grammatical errors
- [ ] Code runs without errors
- [ ] Data is properly de-identified

### Logistics Check
- [ ] Application deadline confirmed
- [ ] All required fields completed
- [ ] Contact information correct
- [ ] References notified (if required)
- [ ] Application saved/submitted before deadline

---

## After Submission

- [ ] Follow up if no response in 2–3 weeks
- [ ] Continue building skills while waiting
- [ ] Prepare for interview (if selected)
- [ ] Keep working on AI safety projects
- [ ] Network with AI safety community
